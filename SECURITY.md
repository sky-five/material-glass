# Security

Material Glass is a CSS library, an optional script with no dependencies, and some small framework wrappers. It doesn't handle data, but the script does touch the DOM, and the demo builder reads image files locally in the browser.

## Supported versions

Fixes land on the latest minor release. Before 1.0, that means the newest `0.x`.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/sky-five/material-glass/security/advisories/new) and include:

- the affected file and version,
- steps to reproduce, or a proof of concept,
- the impact you expect.

You'll get a reply within a week. Fixes are released as soon as they're ready, and the reporter is credited unless they prefer not to be.
