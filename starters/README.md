# Starters

| Starter | Open online |
| --- | --- |
| [Vanilla HTML](vanilla/index.html) | [StackBlitz](https://stackblitz.com/github/sky-five/material-glass/tree/main/starters/vanilla) |

The vanilla starter loads Material Glass from jsDelivr, so it runs anywhere, including by double-clicking the file. Framework starters for React, Vue and Svelte will be added when the `@material-glass/*` packages are on npm. Until then, see the framework sections in the [docs](https://sky-five.github.io/material-glass/guide/frameworks.html).
