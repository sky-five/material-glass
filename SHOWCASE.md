# Showcase

Sites and apps built with Material Glass. To add yours, open a pull request that adds a row, or use the "Showcase" issue form.

| Project | What it is | Theme |
| --- | --- | --- |
| [Material Glass demo](https://sky-five.github.io/material-glass/) | The project site, component catalog and theme builder | All |
| [Weather example](https://sky-five.github.io/material-glass/examples/weather/) | Weather app with a sky that changes with the forecast | Frost |
| [Music example](https://sky-five.github.io/material-glass/examples/music/) | A player that re-themes from album art | Generated |
| [Analytics dashboard](https://sky-five.github.io/material-glass/examples/dashboard/) | Revenue dashboard with charts and a sortable table | Obsidian |
| [Settings example](https://sky-five.github.io/material-glass/examples/settings/) | A phone settings screen that restyles itself | Sand |
| [Landing page template](https://sky-five.github.io/material-glass/examples/landing/) | Product page with pricing and FAQ | Aurora |

## Guidelines

- The project must be public and use Material Glass visibly.
- Use one row per project, with a short plain description.
- Screenshots are welcome in the pull request, but they don't go in the table.
